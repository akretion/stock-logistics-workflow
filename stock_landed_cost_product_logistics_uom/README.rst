This module allows is a glue module between odoo/odoo/stock_landed_cost and oca/product-attribute/product_logistics_uom

It allows to calculate stock_landed_cost on volumes or weight less than 0.01.

**Table of contents**

.. contents::
   :local:

Usage
=====

See parent modules to set really small weight and or volume on a product (for instance 33cl) then
recieve and apply landed costs.

Volume or weight in valuation adjustment lines will still be shown at 0 but the additionnal cost
will be computed.
